    Callback URL: http://127.0.0.1:3000/oauth/callback
    Где взять Client ID и Client Secret

    Откройте настройки аккаунта osu! → раздел OAuth, создайте приложение и укажите Callback URL, показанный выше. Затем сохраните данные здесь и нажмите «Войти через osu!».

    Client Secret хранится только в памяти приложения и не покидает ваш компьютер.

    3. Cookie osu_session — резервный способ

    Нужна, только если зеркала не отдают нужный набор

    Хранится только в оперативной памяти (до 6 часов либо до перезапуска сервера).

    Сессия не добавлена
    Не передавайте cookie никому

    Она даёт доступ к аккаунту. Пароль вводить в это приложение не нужно. Cookie отправляется только на osu.ppy.sh, а не на зеркало загрузок.

    Зеркала — сторонние сервисы

    Если набор не нашёлся, приложение само пробует следующее зеркало. Ничего не найдено — переключитесь на cookie osu_session.

    Обратите внимание

    Скачивание с сессией аккаунта происходит не через официальный клиент. Массовая автоматическая загрузка в обход osu! может, по правилам сервиса, привести к ограничению аккаунта или IP — используйте её умеренно и на свой риск.

    Как это работает

    1. 1Вставьте ссылку коллекции
      Список наборов берётся из публичного API osu!Collector.
    2. 2Скачайте карты
      Файлы .osz приходят с зеркал и сохраняются в папку downloads.
    3. 3Если набора нет на зеркалах
      Добавьте cookie osu_session — загрузка пойдёт напрямую с osu!
    Без входа в аккаунт

    По умолчанию ничего вводить не нужно: зеркала отдают готовые наборы анонимно. Cookie остаётся запасным вариантом для редких наборов.

    Подсказка

    Пример ссылки:

    osucollector.com/collections/23905/stream-180-189

    Каждый .osz содержит набор со всеми его сложностями. Повторные скачивания уже имеющихся файлов пропускаются.
