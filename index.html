    Cookie osu_session даёт полный веб-доступ к вашему аккаунту на osu.ppy.sh. Используйте этот способ только если нужные карты недоступны ни на одном зеркале. Сервер хранит cookie только в оперативной памяти (до 6 часов либо до перезапуска) и маскирует её в логах.

    Как это работает

    1. 1Вставьте ссылку коллекции
      Список наборов берётся из публичного API osu!Collector.
    2. 2Скачайте карты
      Файлы .osz приходят с зеркал и сохраняются в папку downloads.
    3. 3Если набора нет на зеркалах
      Добавьте cookie osu_session — загрузка пойдёт напрямую с osu!
    Без входа в аккаунт

    По умолчанию ничего вводить не нужно: зеркала отдают готовые наборы анонимно. Cookie остаётся запасным вариантом для редких наборов.

    Подсказка

    Пример ссылки:

    osucollector.com/collections/23905/stream-180-189

    Каждый .osz содержит набор со всеми его сложностями. Повторные скачивания уже имеющихся файлов пропускаются.
